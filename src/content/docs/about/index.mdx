## 这是什么

OpenGlass Hub 是一个 AR/AI 眼镜领域的中文知识库网站。我们整理各品牌产品的规格参数、使用场景和开发者资源，为选购和技术决策提供参考。

网站由 [Gaze](https://gaze.dev) 团队发起和维护。

## 为什么做

AR/AI 眼镜品类正在快速扩展，但中文互联网上缺少一份系统化、中立、持续更新的参考资料。各厂商官网信息分散，科技媒体报道偏重时效性，社区讨论碎片化。

我们想做的是一个稳定的、结构化的信息来源。

## 内容立场

- 不售卖任何产品，不接入电商链接
- 不接受品牌付费推广或赞助内容
- 产品信息基于公开资料整理，标注「待核实」的数据正在逐步验证
- 不对任何品牌做主观推荐或排名
- Gaze OS 相关内容单独标注，与第三方产品内容区分

## 内容来源

- 厂商官网公开规格
- 开发者文档和 SDK 说明
- 已发布产品的公开评测
- Gaze 团队的实际开发经验

如发现内容错误，欢迎通过 [GitHub Issues](https://github.com/openglass-hub/issues) 提交修正。

## 参与贡献

OpenGlass Hub 欢迎社区参与：

- 通过 [GitHub Pull Request](https://github.com/openglass-hub/pulls) 提交内容修正或新增
- 在 [GitHub Discussions](https://github.com/openglass-hub/discussions) 参与讨论
- 加入 [Discord 社区](/community) 进行实时交流

## 技术架构

本站基于以下技术栈构建：

- **Astro** + **Starlight** — 静态文档站点框架
- **Markdown/MDX** — 内容格式
- **Cloudflare Pages** — 部署和 CDN
- **Pagefind** — 客户端全文搜索
- **GitHub** — 内容版本管理

全部内容以 Git 仓库管理，通过 Pull Request 流程审核更新。
