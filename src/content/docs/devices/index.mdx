## 对比维度说明

| 维度 | 说明 |
|------|------|
| 显示技术 | Micro-OLED 适合观影，光波导适合透视 AR |
| FOV | 视场角越大沉浸感越强，但通常重量和功耗也更高 |
| 追踪 | 3DoF 仅旋转追踪，6DoF 支持空间定位 |
| 重量 | 轻量设备更适合长时间佩戴 |
| 独立运行 | 是否需要外接手机/电脑 |
