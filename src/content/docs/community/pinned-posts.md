# GitHub Discussions 置顶帖模板

> 以下内容用于创建 GitHub Discussions 的置顶帖。设置 Discussions 后，按以下内容逐条发布并置顶。

---

## 推荐的 Discussions 分类

在 GitHub 仓库 Settings → Discussions 中启用以下分类：

| 分类名 | 类型 | 说明 |
|--------|------|------|
| **Announcements** | Announcement | 官方公告，仅管理员可发帖 |
| **Q&A** | Q&A | 问答，支持标记最佳答案 |
| **Device Reports** | Open | 设备实测报告和使用体验 |
| **Gaze OS Lab** | Open | Gaze OS 相关讨论和反馈 |
| **Ideas** | Open | 功能建议和内容建议 |
| **Corrections** | Open | 内容纠错和数据修正 |

## 置顶帖 1：欢迎来到 OpenGlass Hub

**标题：** 欢迎来到 OpenGlass Hub 社区

**分类：** Announcements

**内容：**

```
欢迎来到 OpenGlass Hub 的社区讨论区。

OpenGlass Hub 是一个 AR/AI 眼镜知识库，整理各品牌产品的规格参数、选购指南和开发者资源。

社区讨论请遵守以下原则：

- 部分产品参数标注「待核实」，如果你有准确信息，请提供来源
- OpenGlass Hub 与任何 AR 眼镜厂商无关联关系
- Gaze OS 目前处于实验性阶段

如有内容修正，建议直接提交 GitHub Issue 或 Pull Request。

感谢参与。
```

## 置顶帖 2：如何提交设备报告

**标题：** 如何提交设备报告

**分类：** Announcements

**内容：**

```
在「Device Reports」分类中分享你的设备使用体验。

建议包含以下信息：

1. 设备型号和购买时间
2. 使用场景（观影、办公、开发等）
3. 佩戴体验（重量、舒适度）
4. 显示效果（亮度、清晰度、FOV 感受）
5. 优缺点总结

如果涉及具体参数，请注明来源：
- 官方规格页面链接
- 实测数据（请说明测试方法）
- 第三方评测链接

我们不对任何品牌做推荐或排名，客观描述即可。
```

## 置顶帖 3：如何报告错误规格

**标题：** 如何报告内容错误或不准确的规格

**分类：** Announcements

**内容：**

```
如果你发现网站上的产品规格或描述有误，可以通过以下方式反馈：

方式一：直接提交 Pull Request
- Fork 仓库，修改对应的 Markdown 文件，提交 PR
- 适合你确定正确信息的情况

方式二：提交 Issue
- 在 Issues 中描述错误位置和正确信息
- 附上来源链接（官方规格页、权威评测等）

方式三：在 Discussions 的 Corrections 分类发帖
- 适合需要讨论确认的情况
- 其他用户可以补充或纠正

标注「待核实」的数据是我们尚未与官方数据核对的预估值。如果你能提供官方来源，优先采用。

所有修正需附带来源，不接受无来源的规格修改。
```

## 置顶帖 4：Gaze OS Lab 反馈

**标题：** Gaze OS Lab 反馈指南

**分类：** Announcements

**内容：**

```
Gaze OS 目前处于实验性阶段，大部分功能尚未实现。

当前可以讨论的内容：
- 系统架构设计方案
- 应用框架概念
- AI 集成方向
- 跨设备适配思路

反馈建议：

- 说明你的使用场景或技术背景
- 描述具体需求，而非笼统的功能请求
- 如果你有技术方案建议，欢迎详细说明

Gaze OS 不是已完成的产品，请基于当前状态讨论，避免与成熟 OS 直接对比。
```

## 置顶帖 5：贡献规则

**标题：** 社区贡献规则

**分类：** Announcements

**内容：**

```
OpenGlass Hub 社区规则：

1. 不发布虚假参数或无来源的规格数据
2. 不人身攻击，尊重不同品牌和用户
3. 不发布广告、推广或无关链接
4. 不发布违法内容或入侵/破解教程
5. 未经验证的信息请标注「待验证」
6. 优先使用官方链接、实物照片或一手体验
7. 尊重品牌商标，不恶意使用或修改品牌标识

内容立场：
- OpenGlass Hub 与任何 AR 眼镜厂商无关联
- Gaze OS 是实验性项目，不代表任何商业承诺
- 所有产品信息基于公开资料，标注「待核实」的数据待验证

违规处理：
- 首次违规：提醒
- 重复违规：限制发帖权限
- 严重违规：永久移除
```
