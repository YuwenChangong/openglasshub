# Gaze Launcher

面向 AR/AI 眼镜的 AI-first 智能启动器

:::caution[开发状态声明]
Gaze Launcher 当前仍在开发中，暂无正式可用版本。
:::

Gaze Launcher 是为眼镜重新设计的主界面。它不是把手机桌面搬到眼镜上，而是把 Home、App Library、Navi AI Assistant 和手机端管理连接到一起，让用户在眼镜上用更少步骤完成任务。

## 为什么需要 Gaze Launcher

很多智能眼镜仍然使用类似手机的操作方式：

打开应用列表 → 找功能 → 进入应用 → 手动操作。

但眼镜不是手机。  
用户在眼镜上更需要的是快速、轻量、少打扰的操作体验。

Gaze Launcher 想做的是：

看见内容 → 启动 Navi → 说出需求 → 得到结果。

例如：

- 看见英文内容，让 Navi 进行翻译
- 看见屏幕信息，让 Navi 帮忙解释
- 需要记录内容，通过语音快速保存
- 需要打开功能，直接用语音、眼动或触控操作
- 需要管理设置，在手机端完成更复杂的操作

## 核心功能

### Home

Home 是 Gaze Launcher 的主界面。

它用于显示常用应用、最近任务、Navi 入口和基础设备状态，让用户进入眼镜后可以快速开始操作。

Home 的目标不是堆满图标，而是让用户更快找到真正需要的功能。

### App Library

App Library 用来整理眼镜上的应用和功能。

它会以更适合眼镜查看的方式展示应用，减少复杂菜单，让用户可以更清楚地找到需要的入口。

常见入口包括：

- Navi AI Assistant
- 翻译
- 拍摄
- 笔记
- 导航
- 设置
- 工具

### Navi AI Assistant

Navi 是 Gaze Launcher 内置的 AI Assistant。

用户可以通过眼镜按键、触控、手机端控制，或说出 “Hello, Navi” 来启动 Navi。

Navi 启动后，用户可以直接说出需要完成的任务，例如：

- “翻译这段文字”
- “解释这个画面”
- “帮我总结一下”
- “记录这句话”
- “打开翻译”
- “打开设置”

Navi 会根据用户的需求调用对应功能，让眼镜不只是显示信息，而是帮助用户理解和处理眼前内容。

## Navi 的启动方式

Gaze Launcher 支持多种 Navi 启动方式：

- 眼镜按键 / 触控启动
- 手机端启动
- 眼动或凝视选择启动
- 可选语音唤醒：“Hello, Navi”

默认情况下，Gaze Launcher 不强制开启语音唤醒。  
用户可以在设置中手动开启：

**Enable “Hello, Navi” wake word**

开启后，Gaze 会使用本地小型 wake word 模型监听 “Hello, Navi”。  
这个模型只用于识别唤醒词，不联网，也不会调用大模型。

如果眼镜设备本身提供系统级语音唤醒能力，Gaze 会优先使用设备自带能力，以获得更低功耗和更稳定的体验。

开启语音唤醒后，设备会使用低功耗麦克风监听唤醒词，可能增加耗电。用户可以随时关闭该功能。

## 按需调用摄像头和麦克风

Gaze Launcher 默认采用按需调用的方式。

用户先主动启动 Navi，然后说出任务。  
只有在任务需要时，Gaze 才会调用对应模块。

例如：

用户说“翻译这篇文章”时，Gaze 可以调用摄像头读取画面内容。  
用户说“记录这段话”时，Gaze 可以调用麦克风进行语音输入。  
任务结束后，相关能力可以停止使用。

这种方式可以减少不必要的打扰，也更适合眼镜的隐私和续航需求。

在会议记录、实时翻译、持续阅读辅助等场景中，用户也可以选择更长时间的工作模式。具体能力会根据不同设备的硬件和系统权限而变化。

## 交互方式

Gaze Launcher 支持多种适合眼镜的操作方式：

- 眼动或凝视选择
- Navi 语音 Agent 操控
- 眼镜按键 / 触控
- 手机端管理与控制

不同设备的硬件能力不同，Gaze 会根据设备支持的输入方式提供对应体验。

## 手机端管理

Gaze Launcher 可以配合手机端管理应用使用。

手机端可以用于完成眼镜上不适合长时间操作的任务，例如：

- 账号登录
- AI 设置
- 设备配置
- 历史记录管理
- 应用管理
- 远程控制
- 输入文字
- 调整显示和声音

这样可以让眼镜端保持轻量，手机端负责更复杂的管理操作。

## 设计理念

### 更少步骤

Gaze Launcher 希望减少用户在眼镜上的操作层级。  
常用任务可以通过眼动、语音、按键或手机端更快完成。

### 更适合眼镜

Gaze Launcher 不直接照搬手机 UI。  
它更适合眼镜的小视野、短时间查看和快速操作。

### AI-first

Navi 不是一个普通应用，而是 Gaze Launcher 的核心入口。  
用户可以直接说出需求，让 Navi 帮助完成下一步。

### 按需感知

摄像头和麦克风不会被设计成无意义地一直工作。  
Gaze 更强调用户主动触发、任务需要时调用、完成后退出。

### 可选语音唤醒

“Hello, Navi” 是一种可选启动方式，而不是强制功能。  
用户可以根据自己的使用习惯，在省电和便利之间选择。

## 目标

Gaze Launcher 希望成为 AR/AI 眼镜上的智能主入口。

它的目标不是替代所有系统功能，而是让用户更快打开应用、理解眼前内容，并通过 Navi 完成任务。
