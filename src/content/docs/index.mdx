## 为什么做这个站

目前 AR/AI 眼镜信息分散在各厂商官网、科技媒体和社交平台，缺少一个中立、系统化的中文参考来源。OpenGlass Hub 试图填补这个空白。

我们不售卖任何产品，不接受品牌付费推广，所有内容基于公开信息整理。

:::note[MVP 阶段]
本站目前处于早期版本。产品规格数据标注「待核实」的条目，正在逐步验证中。
:::
