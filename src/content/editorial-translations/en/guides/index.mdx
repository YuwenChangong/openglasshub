## Begin with the task

A display accessory, camera-equipped smart glasses and a standalone spatial device address different needs. Start with the task you want to complete, then check what the particular device can actually do.

For a portable screen, investigate connection requirements, power, display clarity and comfort. For camera or voice tasks, examine how input is triggered and what happens to captured information. For development, establish the supported installation path and permission boundaries before committing to hardware.

## Verify before deciding

Use manufacturer documentation and device testing to resolve purchase or implementation questions. An available SDK does not by itself establish camera access, background execution or compatibility with a custom runtime. Treat unresolved specifications as unresolved, not as supported features.
