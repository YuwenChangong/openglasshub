# Mobile Responsive Polish Notes

- 主要问题：移动端 header 纵向占用偏大，首页首屏和品牌卡片节奏偏松，产品 name-card 与详情页 hero 在窄屏上过高，圈子与帖子卡片在手机上视觉密度不够稳定。
- 修复范围：仅收紧移动端 header、首页首屏、产品品牌页、设备详情页与通用卡片/媒体间距；不改桌面端信息架构，不改产品数据、审核、权限、RLS、Storage 或来源隐私逻辑。
- 重点保护：logo/avatar/name-card 不拉伸，帖子/评论/设备参数长文本自动换行，品牌卡与帖子操作区不横向挤爆，后台页面在手机宽度下保持基础可用。
